# EPBank

EPBank is a full-stack banking application that simulates core banking operations through a modern web interface. Users can create and manage bank accounts, deposit and withdraw funds, transfer money between accounts, and view their transaction history.

The application is built with Java and Spring Boot for the backend, React and TypeScript for the frontend, and PostgreSQL for persistent data storage. The frontend communicates with the backend through a REST API.

## Tech Stack
### Backend
- Java + Spring Boot
### Frontend
- React + TypeScript
### Database
- PostgreSQL
### API
- REST API

## Planned Features
- Customer registration and login
- View bank accounts
- Open checking and savings accounts
- Deposit funds 
- Withdraw funds
- Transfer funds between accounts
- View transaction history
